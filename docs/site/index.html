FreightFlow

ArcGIS knows where freight can move. FreightFlow coordinates who can share it. MultiFlow determines whether the allocation is admissible. The ledger records what each participant owes.

ArcGIS adapter status

Integration boundary is implemented via NetworkRoute and ArcGISAdapter. v0.2 uses a checked-in deterministic fixture (Dallas → Phoenix). Live ArcGIS routing is not performed and is not claimed. The adapter is the documented entry point for real service responses.
