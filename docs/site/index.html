FreightFlow

Shared freight coordination with deterministic validation, allocation, and settlement.

ArcGIS provides the physical network. FreightFlow coordinates freight across participants. MultiFlow validates whether proposed allocations are admissible. The ledger records the resulting settlement.

Invariant

Proposed allocations are not automatically accepted. MultiFlow (admissibility boundary) + FreightFlow domain constraints must validate first. Rejected candidates never post to the ledger.

Architecture

ARC GIS │ network + geography (fixture in v0.2) │ ▼ ┌──────────────┐ │ FreightFlow │ contracts · shipments · vehicles · economics └──────┬───────┘ │ ▼ ┌──────────────┐ │ MultiFlow │ propose · validate · explain (admissibility) └──────┬───────┘ │ ▼ ┌──────────────┐ │ Settlement │ allocation · ledger · audit trail └──────────────┘

FreightFlow is a vertical domain layer. It does not fork MultiFlow. Docs: ARCHITECTURE.md

Allocation

Deterministic cost shares from a recorded policy (WEIGHT | VOLUME | WEIGHTED_COMPOSITE). Money uses Decimal — no float arithmetic. Reference: 8/5/7 pallets → 40% / 25% / 35% of $1,200 → $480 / $300 / $420.

docs/ALLOCATION.md

Ledger / settlement

Append-only domain ledger. Successful allocations post balanced entries and an explanation chain (what was allocated, which validation authorized it, how each share was computed). Rejected allocations leave the ledger unchanged.

docs/LEDGER.md

ArcGIS integration

Boundary object: NetworkRoute via ArcGISAdapter. v0.2 uses a deterministic fixture (Dallas → Phoenix, source=fixture). Live ArcGIS routing is not performed and is not claimed. The adapter is the entry point for real service responses later.

docs/ARCGIS.md · adapters/arcgis.py

Run the demonstrator locally

This site does not execute the Python demo in the browser. Clone and run:

git clone https://github.com/TheBabelDragon/FreightFlow.git
cd FreightFlow
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install pydantic pytest
export PYTHONPATH=src              # Windows cmd: set PYTHONPATH=src

python examples/shared_freight_demo.py
python examples/conflict_demo.py
pytest -q

Full instructions: README.md
